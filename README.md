# LIFE OS(段階1)

iPhone向けの個人用生活管理アプリ。ビルド不要のHTML/CSS/JSだけで動くPWAです。
データは端末内(IndexedDB)に保存され、外部サービスには送信されません。

## iPhoneで使えるようにする(GitHub Pages・無料)

1. GitHubで新しいリポジトリを作る(例: `life-os`、Publicで可)
2. このフォルダの中身をすべてアップロードする(`test/` は不要)
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/life-os/` で公開される
5. iPhoneの **Safari** でそのURLを開く → 共有ボタン → **ホーム画面に追加**
6. ホーム画面のアイコンから開く(フルスクリーンのアプリとして動く)

PWAの動作(ホーム画面追加・オフライン)には **https** が必要です。ファイルを直接開いただけでは動きません。

## データについて

- 予定・実行記録・状態記録は、それぞれ別の保存領域に分けています。
- 予定を編集しても過去の日は当時の内容のまま残ります(編集は「今日から」の新しい版として記録)。
- 完了の記録は、その時点の名前・時刻・所要時間のコピーを持ちます。
- Safariのタブで長期間開かないと、iOSがサイトデータを消すことがあります。**必ずホーム画面に追加して使ってください。** バックアップ機能(段階3)ができるまでは、重要なデータは入れすぎないでください。

## 通知(段階4で実装予定)

| 方法 | 閉じていても届く | 無料 | 備考 |

| iOSショートカットのオートメーション | はい(確実) | はい | 予定ごとに手動設定が必要。アプリ内に手順を表示する予定 |
| Web Push(PWA) | 基本は届くが遅延・欠落あり | サーバーは無料枠で可 | iOS 16.4以降・ホーム画面追加が必須。実装は大きい |
| アプリ内タイマー | いいえ | はい | 開いている間しか鳴らない |
